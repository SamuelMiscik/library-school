Relační model – Knihovny

  • Library(library id, name, country, city, street, ZIP)
  • Publisher(publisher id, name, country, city, street, ZIP)
  • Book(ISBN, title, publication date, genre, publisher id)
    • FK: (publisher id) ⊆ Publisher(publisher id)
  • Ownership(ownership id, library id, book id, copies)
    • FK: (library id) ⊆ Library(library id)
    • FK: (book id) ⊆ Book(ISBN)
    • UNIQUE: (library id, book id)
    • CHECK: 1 ≤ copies ≤ 5
  • Author(author id, first name, last name, email)
  • Writes(ISBN, author id)
    • FK: (ISBN) ⊆ Book(ISBN)
    • FK: (author id) ⊆ Author(author id)
  • Contract(author id, publisher id)
    • FK: (author id) ⊆ Author(author id)
    • FK: (publisher id) ⊆ Publisher(publisher id)
